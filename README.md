# 🤖 ExcusesMakerAI

> Генератор креативных отговорок на любой случай с помощью AI.

## 📖 О проекте

ExcusesMakerAI — это забавное веб-приложение, которое использует возможности искусственного интеллекта для генерации оригинальных и убедительных отговорок. Проект создан для демонстрации работы с AI-моделями в лёгкой и увлекательной форме.

## ✨ Ключевые особенности

- Генерация уникальных отговорок на основе введённых параметров.
- Интуитивно понятный пользовательский интерфейс.
- Быстрая и простая настройка.

## 🛠️ Технологический стек

- **Backend:** Python, Flask
- **Frontend:** HTML, CSS, JavaScript
- **AI:** Интеграция с внешним AI API

## 🚀 Быстрый старт

1. **Клонируйте репозиторий:**
   ```bash
   git clone https://github.com/KerwekNess/ExcusesMakerAI.git
   cd ExcusesMakerAI
   ```
2. **Установите зависимости:**
   ```bash
   pip install -r requirements.txt
   ```
3. **Настройте переменные окружения:**
   - Создайте файл `.env` в корневой папке.
   - Добавьте в него необходимые ключи (см. `.env.example`).
4. **Запустите приложение:**
   ```bash
   python app.py
   ```
